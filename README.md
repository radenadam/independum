# Independum

An agent harness that puts you in control. Independum runs on your machine and opens in your browser. The goal is that every part of the agent, from the system prompt and injected messages to instruction files and tools, is visible and editable from the UI, and can be turned on or off.

Independum is in early development and not usable yet. See the [roadmap](docs/roadmap.md).

## Development

Requires Node.js 22.19 or newer and pnpm.

```sh
pnpm install
pnpm dev
pnpm check
```

Contributions are welcome, by hand or through any coding agent. The rules live in [AGENTS.md](AGENTS.md).
