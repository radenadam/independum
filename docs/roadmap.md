## Known app defects from step 1

The maintainer supplied these findings directly on 2026-11-15. This list records defects for repair, not verified fixes.

- A one-line new file reads "New, 1 lines" in `packages/web/src/describe-tool-call.ts`.
- A failed Write card omits the model's arguments.
- Any profile edit briefly shows "Loading the tools.", moving the dialog and losing taps because `useChatData` clears data when `load` changes.
- On phones, Jump to the latest message covers a line of a long card.
- On desktop, the running hook row spans the whole chat width.
- File-write approval uses command wording such as "the programs it starts".
- A first message with an attachment puts its attachment note and path in the chat title.
- A text attachment with its path included has an empty Original box.
- Session retains "Failed to fetch" after server restart without page reload.
- Unconfirmed: renaming the leading chat immediately after archiving the open chat may return 404.

## Shipping half

After harness engineering acceptance, make Independum ready as an agent competing with Claude Code, Codex, OpenCode, and Cursor. Add tools for coding-agent parity, including web, collaborating agents, browser, computer use, document and notebook work. MCP and Script are already checkpoint contracts.

Then package for release, write extensive documentation of every part, the GitHub README and website, and add memory across chats. Tailor language, guidance, and learning material for people new to agents within the redesigned structure. Packaging includes startup Node checks, supported-shell guidance, built command and UI, favicon, and npm artifacts. [Decision 0057](decisions/0057-versions-and-checkpoints.md) retains version naming.

Discord, WhatsApp, team services, schedules, and batch runs remain direction only. Each channel uses its own profile and authority. Indonesian support, graphics controls, desktop distribution, interactive terminal, and image and video work remain later questions.
