# Node.js 24

- Status: accepted, and amends [decision 0003](0003-typescript-monorepo-on-node.md)
- Date: 2026-11-05

## Context

Decision 0003 put Independum on Node.js 22.19 or newer, because Pi requires it. The 0.5 checkpoint keeps the commands of the model inside their project with a sandbox of the operating system, and the maintained library that offers it on Windows, macOS, and Linux, Microsoft MXC, requires Node.js 24.21 or newer. Node.js 24 is the current long-term support line, supported until April 2028, and Node.js 22 until April 2027. The maintainer chose to require Node.js 24 over keeping Node.js 22 without a sandbox.

## Decision

- Independum requires Node.js 24.21 or newer, in `engines` of the root `package.json`.
- pnpm refuses to install on an older Node.js, through `engineStrict` in `pnpm-workspace.yaml`, so its message names the required version before anything runs.
- CI checks Node.js 24 on Windows, macOS, and Linux, and no longer Node.js 22.

## Consequences

- One Node.js line to test, and the sandbox can run wherever Independum runs.
- The command that 1.0 packages also needs to check the version when it starts, because npm installs a package on an older Node.js with only a warning. The packaging item of the roadmap says so.
