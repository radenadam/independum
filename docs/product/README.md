# Product areas

These pages describe the current implementation. Start with the area that changes. Decision records explain the choices, and the linked code holds the behavior. Each area lists known differences from its decisions at the end, with source lines.

- [Chats](chats.md): sidebar, drafts, export, notifications, and independent runs.
- [Message box](message-box.md): sending, model choice, thinking effort, and the context meter.
- [Replies](replies.md): text, thoughts, steps, groups, notes, and copying.
- [Side panel](side-panel.md): tabs, Session, its figure and conversation, Commands, and details.
- [Settings](settings.md): logins, browser choices, tool controls, model texts, and texts of Pi.
- [Tools](tools.md): the shared contract and the six built-in tools.
- [Server](server.md): chat lifecycle, storage, API routes and payloads, access control, and model input.

Use the terms in the [glossary](../glossary.md). UI files below are in `packages/web/src`, and server files are in `packages/independum/src`. Source links resolve from each page to those files.
