# Glossary

[Product pages](product/README.md#area-router) own behavior. [Decisions 0081](decisions/0081-harness-engineering-and-two-halves.md) and [0083](decisions/0083-components-removal-and-origin.md) record direct maintainer product answers of 2026-11-15 and delegated choices. Preserve current schema names.

| Term | Meaning |
| --- | --- |
| Access token | Local control secret. |
| Added fact | Controlled model input fact. |
| Agent | Model and configured harness mechanisms. |
| Approval | Resource authority with lifetime. |
| Archived chat | Chat outside ordinary navigation. |
| Attachment | Original with model delivery. |
| Background command | Shell work after tool return. |
| Branch | Message path, separate from files. |
| Channel | Agent destination or trigger with separate profile and authority. |
| Chat | Saved messages, currently formatted by Pi. |
| Commands | Place for Shell work. |
| Compaction | Summarizing older context, retaining recent. |
| Component | Part outside the kernel. |
| Component protocol | Language-neutral kernel and component communication. |
| Context | Available model input. |
| Context engineering | Assembling model input, including earlier turns. |
| Denied path | Path inaccessible to project tools. |
| Detach | End profile contributions, keep installation. |
| Easy | Traceable causes, no cliff, safe experiments, fast feedback, sharing, explanations, few concepts. |
| Envelope | Source tag around a harness note. |
| Fingerprint | Hash identifying file content. Avoid snapshot. |
| Follower | Client holding a chat event stream. |
| Harness | Mechanisms around model calls. |
| Harness engineering | Changing harness mechanisms for a workflow. |
| Headless mode | Control without browser or interactive terminal. |
| Hook | Observer or transformer, becoming loop stage. |
| Hook invocation | Captured hook execution and effect. |
| Independum | Harness engineering tool, easy and transparent. |
| Kernel | No harness decisions. Connects through Pi, makes and saves exact single calls, exposes engineering controls. |
| Login | Provider access through sign-in or key. |
| Login session | In-progress provider login. |
| Loop | Replaceable component running requested tools, returning results, repeating until done. |
| Maintainer | Owns meaning, audience, first encounters. |
| Model | Selected provider-run model. |
| Model override | Value replacing a catalog setting. |
| Model text | Individually controlled model-facing wording. |
| Modular | Nonkernel parts detach or delete. |
| Note | Source-labeled harness message, possibly waking work. |
| Notification | Reply completion notice. |
| Operation | Waitable work, currently through Pi settlement. |
| Origin | Component maker: Independum, user, MCP server. |
| Paired browser | Revocable phone browser authority. |
| Permission rule | Resource allow, ask, or deny policy. |
| Phone access | Separate private HTTPS listener. |
| Pi | Owns providers, logins, models. Current loop awaits replacement. |
| Pinned chat | Chat atop the sidebar. |
| Place | Destination in a side-panel tab. |
| Profile | Complete setup in authoritative files. |
| Project | Chat's working folder. Avoid workspace. |
| Project instructions | Discovered literal instruction files. |
| Prompt variant | Prompt alternative and descendants. |
| Provider | Service running models. |
| Recent chats | Five newest unpinned chats. |
| Remove | Delete component from disk. Restore by download. Settings deletion stays explicit. |
| Reply | Answer spanning model turns. |
| Reply attempt | One prompt variant run. |
| Request | Model-turn input. Reconstruction is not capture. |
| Sandbox | Operating system boundary for workers and descendants. |
| Script tool | Short-program parameter calls other tools as functions, regardless of source. |
| Session | Place inspecting setup, context, requests. |
| Shell | Command tool using selected shell. |
| Side panel | Right column holding places. |
| Sidebar | Chat navigation and Settings column. |
| Skill | `SKILL.md` resource with metadata. |
| Slash command | Leading action, prompt, or skill invocation. |
| Slot | Model text value position. |
| Stage | Engineerable loop step, including hook events. |
| Step | Agent action, including tools. |
| Step group | Foldable work between reply texts. |
| Submission | Durable input with operation reference. |
| Thought | Model reasoning, distinct from action. |
| Tool contract | Universal name, description, parameters, execution, editable texts. |
| Transparent | Model input and harness behavior visible, recorded, reproducible. |
| Turn | Model response, including tool calls. |
| User | Person using Independum. |
| Waiting message | Input held until delivery. Code says pending input. |
| Working screen | Chat, sidebar, side panel. |

Built-in and add-on kinds retire. Use origin. Built-in text labels describe defaults.
